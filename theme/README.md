# Endgame — Omarchy theme

*Ancient chess strategy reconstructed inside a modern terminal.*

Near-black surfaces, warm ivory text, muted green accents and restrained gold.
The wallpapers are cinematic; the UI stays quiet so the desktop remains
practical. Built for and verified on **Omarchy 4.0.2** (Quickshell shell,
Hyprland Lua config, `colors.toml` template system).

Activate: `omarchy theme set endgame`

`omarchy theme set endgame`.

## Files in this directory

| File | Purpose |
|---|---|
| `colors.toml` | Semantic palette; source of all generated app themes |
| `hyprland.lua` | Window styling: gaps 3/6, border 2px green→gold gradient, inactive border `#202820`, rounding 4, soft shadow |
| `icons.theme` | `Yaru-sage-dark` (closest installed Yaru variant to the muted-green palette; prussiangreen reads teal, olive reads yellow-green) |
| `shell.bar.toml`, `shell.lock.toml`, `shell.launcher.toml`, `shell.menu.toml`, `shell.notifications.toml`, `shell.popups.toml` | Section overrides merged into the generated `shell.toml` (Omarchy's `shell.<section>.toml` mechanism). Only these sections are pinned; everything else keeps upstream defaults |
| `shell.branding.toml` | Endgame identity strings (bar label, workspace glyphs, lock screen texts/wallpaper). Read by the user plugins listed below |
| `prompt.txt` | Terminal prompt badge (`♞`), read by the starship module described below |
| `menu.jsonc` | Launcher/menu overrides applied by the theme-menu hook while this theme is active (see "Files outside this directory") |
| `preview.png` | Theme-picker preview (crop of the default wallpaper) |
| `backgrounds/` | The eight wallpapers |

Not shipped: `unlock.png` / `preview-unlock.png`. Omarchy 4.0.2 does not
reference them anywhere outside the stock theme folders (they are left over
from the hyprlock era); the Quickshell lock screen has no unlock art slot.

Switch wallpapers: `omarchy theme bg next`, or `SUPER + CTRL + SPACE` for the
picker, or `omarchy theme bg set <path>`.

Add or replace wallpapers: drop images into `backgrounds/` (keep the numeric
prefix to control order) and run `omarchy theme set endgame`. Additional
personal wallpapers can also go in `~/.config/omarchy/backgrounds/endgame/`
without touching the theme.

## Lock screen

Rendered by the `jim.lock` plugin (see below). It shows a large clock, the
date, `YOUR MOVE`, a small bordered password field with a knight, and the
captions `OMARCHY // ENDGAME` / `POSITION LOCKED`. All of that comes from
`shell.branding.toml`:

- `lock-background` — file name inside `backgrounds/` (empty = current wallpaper)
- `lock-blur`, `lock-dim` — 0..1, applied at render time (the image file is untouched)
- `lock-icon`, `lock-subtitle`, `lock-brand`, `lock-status`, `lock-time-format`, `lock-date-format`

Preview without locking: `omarchy-shell lock preview` (click to dismiss, or
`omarchy-shell lock hidePreview`). Input field colours are in `shell.lock.toml`.

## Terminal prompt identity

The prompt shows `♞ ~/project ❯`. The badge text is the content of
`prompt.txt` in this directory — change it to anything (e.g. `♞ endgame`) and
re-run `omarchy theme set endgame`. The username is not hard-coded anywhere;
if you want it shown, add `$username` to `format` in `~/.config/starship.toml`
with `[username] show_always = true`.

## Workspace glyphs

`shell.branding.toml` → `workspace-glyphs` / `workspace-active-glyphs`, one
glyph per workspace id. Semantic order: 1 King (command), 2 Queen (web),
3 Rook (terminal), 4 Bishop (code), 5 Knight (communication), 6 Pawn (misc).
Workspaces 7–10 show numbers. No app-to-workspace rules are enforced.

Values in `shell.branding.toml` must stay ASCII: write glyphs as `\uXXXX`
(the shell's theme-switch IPC decodes the file as Latin-1, which would mangle
raw UTF-8; the plugins decode the escapes).

## Files outside this directory

All changes are user-level, survive `omarchy update`, and were backed up to
`~/.config/omarchy/backups-endgame/` before editing.

| Path | Change | Why | Revert |
|---|---|---|---|
| `~/.config/omarchy/plugins/jim.lock/` | Clone of `omarchy.lock` (`omarchy plugin clone`). `Service.qml` is byte-identical to stock; only `LockView.qml` (presentation) was rewritten | Stock lock screen has no clock, no captions, and a large 381×67 input box; themes can only recolour it | `omarchy plugin remove jim.lock` restores the built-in |
| `~/.config/omarchy/plugins/jim.workspaces/` | Clone of `omarchy.workspaces`; renders `[branding]` glyphs, stock numbers otherwise | Workspace labels are code, not theme data | `omarchy plugin remove jim.workspaces` |
| `~/.config/omarchy/plugins/jim.brand/` | New bar widget replacing the `omarchy.menu` button; shows `[branding] bar` or the stock logo. Same clicks (left = menu, right = terminal) | The bar logo is code, not theme data | `omarchy plugin remove jim.brand`, then `omarchy bar put omarchy.menu --section left --index 0` |
| `~/.config/omarchy/shell.json` | `omarchy.menu` → `jim.brand` in `bar.layout.left`; clone bookkeeping (`jim.workspaces`, `jim.lock`, `disabledPlugins`) written by the clone command | Bar layout lives here | Restore `backups-endgame/shell.json.pre-endgame` |
| `~/.config/starship.toml` | Added `[custom.omarchy_theme_badge]` and `${custom.omarchy_theme_badge}` at the start of `format` | Theme-owned prompt badge; hidden when the active theme has no `prompt.txt` | Restore `backups-endgame/starship.toml.pre-endgame` |
| `~/.config/omarchy/hooks/theme-set.d/theme-menu` | Symlink to `hooks/theme-menu` in the repo. On every theme switch it writes the active theme's `menu.jsonc` (this theme: launcher header `YOUR MOVE`, knight icon on Apps) into the extension file below between marker comments, or removes the block for themes without one | The menu extension file is global; the hook makes its Endgame part follow the theme | Remove the symlink; delete the marked block from the extension file; `omarchy menu refresh` |
| `~/.config/omarchy/extensions/omarchy-menu.jsonc` | Contains a hook-managed block between `// >>> theme menu` and `// <<< theme menu` while Endgame is active | Written by the hook above | Handled by the hook; or delete the block by hand |

Switching to any other theme keeps the plugins and hook active but they fall
back to stock automatically (Omarchy logo, numbered workspaces, plain lock
screen with the current wallpaper, no prompt badge, stock menu headers).

## Limitations (Omarchy 4.0.2)

- Launcher placeholder and "No matches" text are hard-coded in the menu plugin; `No legal moves.` was not forced in. The header and Apps icon come from `menu.jsonc` via the hook.
- Notifications have three urgencies (low/normal/critical); there is no separate "warning" level, so gold is not used there. Critical uses `red`.
- OSD segments/board pattern are not themeable; OSD follows `[popups]` (thin green border).
- Hyprland has no urgent-window border colour; urgency is shown by the bar's attention colour (gold).
- If the global "no gaps" toggle (`SUPER + SHIFT + BACKSPACE`) is on, Hyprland shows 0 gaps/borders/rounding regardless of theme.
- Chess glyphs come from Noto Sans Symbols 2 via font fallback (JetBrainsMono Nerd Font has none).
